# Town 主题与叙事决策

> **状态：** 产品口径（叙事 / 角色 / 地点）。不改经济、不改解锁规则。  
> **结论先行：** 货架是 **Arcade League**。主场布局永久。**Town 和 Island 都是赛季主题**，不是永久世界。职称随主题换（镇季 Mayor，岛季岛主）。

---

## 0. 一句话决策

玩家拥有的是 Arcade League 里 **一块自己的主场**：玩赢了建筑留下，别人能来拜访。  
主场的 **地貌和称号随赛季换皮**：有的季是岛，有的季是镇。产品不是一座岛，也不是一座镇。

| 层 | 锁定 | 不锁定 |
|----|------|--------|
| 循环 | 竞技解锁 + 访客可见的主场 | 市政模拟、种田、第二套养成货币 |
| 所有权 | 永久 `steward`：这块主场是你的 | 把所有权写成 Mayor 或岛主本人 |
| 赛季主题 | **biome 池：`island` / `town` / …**；每季选一个 | 把 Island 或 Town 写成永久世界 |
| 本季职称 | 随 biome：岛季 **岛主**，镇季 **Mayor** | 海岛长官、Governor、Chief |
| 赛季叙事 | 第 N 季 Arcade League + 主题名（岛季 / 镇季） | 永久「岛赛」、镇长换届当产品身份 |
| 产品名 | **Arcade League** | Isle League、Your Island、Mayfield |
| 被动产业 | 竞技 charge → 建筑熟成 → `homeSpark`（只换外观） | 离线产币、工人、生产链 |
| 布局 | 同一套建筑槽位 / Gate，只换地貌与外壳 | 每季重做一张地图 |

**Town 和 Island 可以同时存在吗？** 可以，而且应该：它们是赛季主题，不是二选一的产品设定。见 §12。  
**被动产业？** 只做竞技成绩的熟成罐，不做离线工厂。见 §13。  
**首季默认：** `island`（覆盖更宽）。Town 作为后续季主题，消化 Mayor 任期隐喻。  
**游戏叫什么？** 货架锁 **Arcade League**。见 §11。

---

## 1. 为什么现在会纠结

仓库里其实已经有 **两套 Town、三套皮**，还没有统一「玩家是谁」。

| 表面 | 玩家像谁 | 地点 | 承担的工作 |
|------|----------|------|------------|
| Portal `/town` M1 | 西部小镇的过路人 / 隐含镇长 | Mayfield · Saloon Row（沙尘、扑克沙龙、电报局） | 空间大厅：走进建筑 = 进游戏 |
| CasualTown | 有皇冠纹章的领主 | 山谷卡通村（风车、喷泉、竞技场、招财猫） | 成就展柜 + 轻拜访 |
| 赛季皮肤 | 未定义 | S1 草地天空 / S2 江户樱花 | 换墙纸，不换身份 |

纠结 Mayor vs 岛主，本质上是把三件事捆在一起问了：

1. **循环：** Town 是养成模拟，还是竞技主场？
2. **角色：** 玩家是执政官，还是这块地的主人？
3. **地点：** 西部镇、海岛、还是现在这张山谷村？

Mayor 和海岛长官只回答了 2+3，而且用的是同一句台词：「你来管这块地」。  
**真正要先锁的是 1。** 本仓库已定：Town 是展示与轻社交，**不是**与赛季锦标并行的第二养成主循环（见 `docs/CLAUDE.md` §5）。

所以：任何听起来像《Township》《海岛奇兵》的职称，都会 **超卖一个我们不打算做的循环**。

## 2. 先拆开：循环 / 角色 / 地点

### 2.1 循环（已定，主题必须服从）

玩家实际在做的事：

- 去建筑里 **玩游戏**（M1 Gate：Solitaire Parlor → 进局）
- 靠竞技成绩 **解锁永久建筑**（0 个可买）
- 别人能 **看见** 这座主场

玩家 **没有** 在做的事：批地、收税、派工人、升级民居产金币。

因此叙事动词应是 **留下痕迹 / 主场变强**，不是 **执政 / 开发荒地**。

### 2.2 角色（对外一句话，对内一个 id）

好的角色只有一个测试：

> 不解释规则，玩家是否明白「这是我的地，不是服务器公共广场」？

| 职称 | 何时用 | 结论 |
|------|--------|------|
| `steward`（系统） | 永远，不出现在 UI | 所有权 id |
| 岛主 / Island Keeper | biome = `island` 的那一季 | 本季称号，不是永久身份 |
| Mayor / 镇长 | biome = `town` 的那一季 | 本季称号；任期 = 这一季。见 §12 |
| 海岛长官 / Governor / Chief | 从不 | 否决 |
| 你的主场 / your grounds | 跨季兜底、拜访入口 | 主题未加载时的中性词 |

系统层不要把 `mayor` 或 `island_keeper` 写成永久枚举。用 `steward` + 本季 `biomeId` → 称号表。

### 2.3 地点：Town / Island 都是赛季 biome，内部仍可叫 town

**玩家看见的永久世界名是主场，不是岛也不是镇。** 本季 HUD 可以喊「你的岛」或「你的小镇」，那是主题口吻。

| biome | 玩家向？ | 进游戏隐喻 | 何时用 |
|-------|----------|------------|--------|
| `island` | 作为 **赛季主题** | 码头、灯塔、上船 | 首季默认；覆盖更宽时 |
| `town` | 作为 **赛季主题** | 客厅、市政厅、主街 | 后续季；消化 Mayor 任期 |
| 山谷卡通村（现母图） | 占位美术 | 进地标 | M1 过渡，不算一种 biome 设定 |
| Mayfield 西部 | 否，不当品牌 | 沙龙 | 可做 `town` 季的一款外壳，不当世界名 |

同一套建筑槽位：Parlor / Saloon / Hall / Telegraph 换外壳，不换 id。  
岛季：码头牌屋、夜航船、灯塔、信鸥站。  
镇季：客厅、沙龙、市政厅、电报局。

下一张主插画先按 **可换皮的同一布局** 来：中央广场 + 若干 Gate，水域和主街都是可开关的环境层（已有 env / accent / facade / full）。不要做两张不能共用槽位的地图。

### 2.4 为什么首季默认 Island，但仍保留 Town 当季主题

Island 比 Town 更贴当前潮流、覆盖更宽（年龄、地区、休闲目录）。所以 **第一季默认 `island`**，不是因为 Town 非法。

Town 作为赛季主题仍然有用：

- Mayor 任期终于能合法对上 season（只在镇季）
- 西部 / 主街 / 冬日小镇是可运营的换季内容
- 已有 Mayfield M1 和山谷母图能当 `town` 季素材，不必扔掉

不要把「Island 覆盖更宽」理解成「永远不许出现镇」。那会把换季池砍掉一半。

## 3. 对 Mayor 的具体判断

Mayor 不适合当 **产品身份**，适合当 **镇季称号**。

适合 Mayor 当品牌的产品：Town 本身就是玩法。本产品：Town 是大厅 + 奖杯柜。若永远自称 Mayor of Mayfield，会三种错位（公共城、西部沙龙门面、锁死换季）。

放进赛季主题后，这三种错位都消失：

- 所有权在主场 / `steward`，不在镇长
- 西部沙龙只是这一季的外壳
- 下一季可以换成岛，Mayor 自然卸任

**任期 = 这一季的镇主题。** 季末不是罢免主人，是换主题。建筑留下，称号换。这和「主场不随赛季重置、赛季分会重置」同构。

---

## 4. 对「海岛长官 ≡ Mayor」的判断

等价关系成立，而且正是风险：

```
Mayor + 西部镇  ≈  长官 + 海岛
     steward + 地点皮
```

换地点 **能** 解决观感（更休闲、更好换季、更不像赌场）。  
换职称 **不能** 解决循环（长官和 Mayor 一样在卖「你来治理」）。

所以：

- 要海岛：作为 **赛季 biome**，首季默认。不是永久世界。
- 要 Mayor：作为 **镇季称号**，任期=这一季。不是货架品牌。
- 要长官：不要。岛季用岛主，镇季用 Mayor。

## 5. 推荐的玩家向叙事（永久主场 + 本季主题）

**永久身份：** 这是你在 Arcade League 的主场。  
**本季（岛）：** 你是岛主。去码头屋子里玩游戏；赢了，岛上多一样别人看得见的东西。  
**本季（镇）：** 你是本季 Mayor。去主街屋子里玩游戏；赢了，镇上多一样别人看得见的东西。  
**别人来做什么：** 拜访你的主场，看见你的建筑，必要时从公告板发起挑战。  
**不是什么：** 不用把岛建成都市、也不用把镇建成城市才能玩。

成长阶段内部 id 仍是 `village → town → city → …`。对外按 **当前 biome** 换口吻，不改数值。跨季兜底用「主场」：

| 内部 stage | 岛季 | 镇季 | 跨季兜底 |
|------------|------|------|----------|
| 小村庄 | 荒滩营地 | 驿站 | 主场 Lv.1 |
| 小镇 | 你的岛 | 你的小镇 | 主场 |
| 城市 | 港湾岛 | 主街 | 主场 |
| 都市 | 夜岛 | 夜镇 | 主场 |
| 传奇之城 | 传奇岛 | 传奇镇 | 传奇主场 |

内部路由继续 `/town`。玩家向字符串跟本季 biome，不要写死只用 island 或只用 town。

## 6. M1 建筑怎么讲（先改词，不重画）

M1 工程可以继续跑 Mayfield 原型。**document title 用 Arcade League。**  
若 M1 上线窗口仍是占位图：口吻跟 **即将到来的首季 biome（建议 island）**，或暂时用中性「主场」，不要把 Mayfield 写成品牌。

同一 `id`，两套显示名：

| id | 岛季 | 镇季 | 功能 |
|----|------|------|------|
| `town_hall` | 灯塔 / 岛主小屋 | Town Hall | 身份、进度 |
| `parlor` | 码头牌屋 | Solitaire Parlor | Gate → Solitaire |
| `saloon` | 夜航船（M2 gated） | Poker Saloon（M2 gated） | 扑克 |
| `telegraph` | 信鸥站 | Telegraph | 拜访 / 消息 |

Quest：岛季 `在码头牌屋打完 1 局`；镇季 `Play 1 game at the Parlor`。

## 7. 明确不做什么

1. **不为了叙事重做经济或解锁。** 建筑仍然只能竞技解锁。
2. **不把 `/town` 和 CasualTown 做成两个世界。** 玩家只有一块主场。
3. **不把西部镇或岛做成永久世界品牌。** 二者都是赛季主题。
4. **不引入必须天天喂养的吉祥物。**
5. **不在 M1 为每个 biome 各画一张不能共用槽位的地图。** 下一张插画按可换皮布局；env/accent/facade/full 继续用。
6. **不以岛/镇/Mayor 做商店主名。** 货架锁 Arcade League。
7. **不每季重做建筑 id。** 只换显示名与外壳。
8. **不把「岛主」或「Mayor」写成跨季永久职称。** 跨季所有权只说主场 / `steward`。

## 9. 若否决本结论，最小替代

可接受的弱化：首季只用 island，Town 主题排到更后面；或称号全部改成无职称的「你的主场」。

不要选：把 Island 或 Town 写成永久世界；Isle League / Mayfield 当货架名；每季一张不能共用槽位的新地图。

现有山谷母图 / Mayfield 继续当占位，等于 **还没切 biome 包**，不等于产品是镇或岛。

## 10. 赛季怎么映射：主题季，不是主人换届

永久的是主场和建筑。转的是 biome、称号、赛季分、Pass。

| | 永久 | 本季（island） | 本季（town） |
|--|------|----------------|--------------|
| 玩家是谁 | 主场主人 `steward` | 岛主 | Mayor（任期=这一季） |
| 系统 | 建筑、Town Level、档案室 | 赛季分、Pass、周联赛 | 同左 |
| 季末 | 主场还在，本季旗帜入库 | 卸下岛主称号，开下一季主题 | 卸下 Mayor，开下一季主题 |
| 口吻 | 你的主场 | S2 樱花岛季 | S3 主街镇季 |

Mayor 任期只在 **镇季** 合法：任期结束 = 主题卸下，不是把主场收走。  
岛季不要说「岛主任期」——岛主是主题称号，赛季结束换皮即可。

通用赛季名：**Arcade League Season N / 第 N 季**。  
主题名叠在后面：岛季、镇季、樱花岛季。不要把所有赛季都叫「岛赛」。

## 11. Arcade League vs Isle League：仍锁 Arcade League

Town / Island 改成赛季主题之后，**更不能**用 Isle League 当货架名：下个季可能是镇，名字会过期。

| 层 | 名字 |
|----|------|
| 产品主名 | **Arcade League** |
| 主场（跨季） | 你的主场 |
| 本季世界口吻 | 你的岛 / 你的小镇（跟 biome） |
| 本季赛事 | 第 N 季 · 岛季 / 镇季 |

副标题用中性竞技句，岛不要写死：  
`Play casual games. Climb the season. On your home ground.`  
中文：`休闲小游戏，赛季积分，在你的主场比。`

图标：联赛/奖杯为主；当前季可用小岛或主街作点缀，不要画街机柜子。  
中文不要译「街机联赛」。

否决货架名：Isle League、Your Island、Mayfield、Island Games、Casual Lobby、Match 3、PlayMint、Branwar Games。

`documentTitles` town shell → `"Arcade League"`。

## 12. Town 和 Island 作为赛季主题（本题）

**可以，这是正选。** 不要再把二者当成产品世界的二选一。

已有系统几乎就是这个结构：赛季 Pass、`cssThemeKey`（S1 天空 / S2 樱花）、Town 的 env → full 分层。缺的只是把 **地貌（biome）** 和 **称号** 收进同一份赛季包，而不是只换墙纸。

一份赛季主题包建议包含：

| 字段 | 例：岛季 | 例：镇季 |
|------|----------|----------|
| `biomeId` | `island` | `town` |
| 称号 | 岛主 | Mayor |
| 主场口吻 | 你的岛 | 你的小镇 |
| 建筑显示名 | 灯塔 / 码头牌屋 / … | Town Hall / Parlor / … |
| 环境层 | 海、码头、夜岛 | 主街、沙尘或冬日灯 |
| 赛季名 | 第 2 季 · 樱花岛季 | 第 3 季 · 主街镇季 |

约束（不然会做成两个游戏）：

1. **同一布局。** 槽位、Gate、解锁进度跨季还在。换的是外壳。
2. **首季 `island`。** 覆盖更宽；Town 放后续季，顺便用上 Mayfield 素材。
3. **樱花不是第三种 biome。** 它是 dress，可以叠在岛上或镇上（江户樱花镇 / 樱花港）。
4. **不要每季新循环。** 主题包只换皮和文案，不换经济。

这样：Island 的潮流覆盖、Town 的 Mayor 任期、Arcade League 的竞技主名，可以同时成立。

## 13. 被动产业：熟成，不是离线工厂

Town 可以有「产业」观感，**不能**有 Township / 海岛奇兵式离线产币。  
已定铁律：主场是展示层，**不**做成与赛季锦标并行的发币轨。被动产业必须服从这条。

### 13.1 一句话

产业是 **把已经打出来的竞技成绩，放进建筑里熟成，引诱回访**。  
时间不产东西；没比赛就没有原料。

| | 不要（经营模拟） | 要（Arcade League） |
|--|------------------|---------------------|
| 原料 | 墙钟、工人、小麦 | 本局胜利 / 周联赛 XP / 拜访 |
| 时间做什么 | 生产 | **熟成**：把已有 charge 变成可领取的余韵 |
| 产出 | 金币、材料、战力 | **主场余韵** `homeSpark`（只换主场外观） |
| 不上线 | 照样发财 | 罐是空的 |
| 付费 | 秒建筑、买工人 | 至多：看广告领一次余韵；不加速赛果 |

### 13.2 为什么不能做真·被动产币

- 会变成第二养成，和接龙/方块/Merge 抢会话。
- CrazyGames 短会话：离线 12 小时产的钱若超过打 3 局，主循环死亡。
- 建设点已经规定 **只能竞技获得、不可购买**。产业若再印 Town Points / coins / 赛季 XP，铁律作废。
- 岛季「潮汐磨坊」+ 镇季「市长工坊」很容易滑成模拟经营，产品会从 Arcade League 读成经营岛。

### 13.3 结构：同一栋建筑，多一个罐

不新开一排工厂。已有建筑加 `cask`（熟成罐）：

| 建筑 id | 岛季外壳 | 镇季外壳 | 原料（charge） | 熟成后 |
|---------|----------|----------|----------------|--------|
| `parlor` | 码头牌屋 | Solitaire Parlor | 接龙对局结算 | 牌屋余韵 |
| `arena` | 潮汐场 | 竞技场 | 周联赛 League XP | 星尘余韵 |
| `game_museum` | 沉船馆 | 游戏博物馆 | 三玩法各有对局 | 展品余韵（外观） |
| `season_archive` | 岛季档案 | 镇季档案 | 本季赛季 XP | 旗帜碎（本季 dress） |
| `visitor_log` | 码头访客 | 留言墙 | 他人拜访 | 极少量余韵（社交钩，不是礼物经济） |
| `saloon` | 夜航船 | Poker Saloon | M2 前不产 | — |

解锁条件仍是原来的竞技成就。没有「买一个磨坊」。

流程：

1. 打完一局（或拿到 League XP）→ 对应建筑 **立刻获得 charge**（服务端写）。
2. charge 在墙钟上按小时 **熟成** 成可领 `homeSpark`（例如 2–4 小时把本罐 charge 转完）。
3. 玩家回主场点建筑 **领取**。罐满则停止熟成（要回来倒掉）。
4. 当日未比赛：没有新 charge，过夜不会凭空长出余韵。

### 13.4 产出与上限（量级，不是配表）

`homeSpark` 只能花在：主场环境层、建筑外壳、本季 biome 点缀。  
**不能**兑 coins、tickets、赛季 XP、Town Points、再战令。

量级（正式配表走经济 SSOT，这里只锁关系）：

- 打 1 局当场拿到的主循环奖励（分、币、券）**远大于** 这局送进罐里、数小时后领到的余韵。
- 全日被动领取 ≤ 当日主动打满日赛上限的 **约 20–30% 观感价值**，且价值只在主场外观。
- 每罐可积约 **4–8 小时** 熟成，诱导回访，不要 24 小时当班。
- 每日领取次数可封顶（2–3 次），避免挂机点收集。
- 拜访产出必须更小，且 **不能互刷**（同对手冷却、日上限）。

### 13.5 赛季主题怎么叠

罐的规则跨季不变。换的是 VFX 和文案：

- 岛季：潮水、渔获、灯塔雾；领取像收网。
- 镇季：烟囱、工坊、市政税箱（口吻可以「本季市政余韵」）；**不是真收税**。
- 季末：未领余韵可进档案室当「本季工坊旗帜」，或按衰减兑成下一季 spark。不要把罐清成惩罚。

Mayor / 岛主只是领取时的称号，不加成产量。产量只跟竞技 charge。

### 13.6 变现边界

允许：广告领取一次已熟成的余韵；Pass 给外壳。  
禁止：花钱清空熟成时间来拿 coins / XP；买工人；产业等级影响赛果或门票。

### 13.7 明确不做什么

- 生产链（麦→面包→酒）
- 工人、人口、幸福度
- 离线时间当原料
- 产业科技树
- 用产业发赛季分或门票
- M1 就做全图工厂

落地顺序：M1 主场 + Gate，**无罐**。下一档只给 `parlor` 一个罐，验证回访，再铺其它建筑。
