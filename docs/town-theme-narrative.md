# Town 主题与叙事决策

> **状态：** 产品口径（叙事 / 角色 / 地点）。不改经济、不改解锁规则。  
> **结论先行：** 保留「这块地是你的」骨架；**不要把产品品牌写成 Mayor of Mayfield**；默认消费者角色用 **岛主**，地点用 **海滨家园**。海岛长官 ≈ Mayor，只是换皮，不能单独解决问题。

---

## 0. 一句话决策

Town 不是一座需要你执政的公共城市，而是 **玩家个人的主场**：玩赢了就留下痕迹，别人能来看。

| 层 | 锁定 | 不锁定 |
|----|------|--------|
| 循环 | 竞技解锁 + 访客可见的主场（已有 Town 原则） | 市政模拟、工人、种田、第二套养成货币 |
| 角色 | 这块地的主人（系统 id：`steward`） | 写死 Mayor / Governor / 长官 |
| 默认皮 | 岛主 + 海滨家园 | 西部 Mayfield 作为世界身份 |
| 换皮 | 赛季只换地点外观与称号文案 | 换循环、换「这是谁的地」 |

**Mayor 合适吗？** 作为内部隐喻（建筑 = 入口、主场会长大）可以用；作为对外身份不合适。  
**海岛长官更好吗？** 地点更好，职称更差。要用海岛，职称用 **岛主**，不要用长官。

## 1. 为什么现在会纠结

仓库里其实已经有 **两套 Town、三套皮**，还没有统一「玩家是谁」。

| 表面 | 玩家像谁 | 地点 | 承担的工作 |
|------|----------|------|------------|
| Portal `/town` M1 | 西部小镇的过路人 / 隐含镇长 | Mayfield · Saloon Row（沙尘、扑克沙龙、电报局） | 空间大厅：走进建筑 = 进游戏 |
| CasualTown | 有皇冠纹章的领主 | 山谷卡通村（风车、喷泉、竞技场、招财猫） | 成就展柜 + 轻拜访 |
| 赛季皮肤 | 未定义 | S1 草地天空 / S2 江户樱花 | 换墙纸，不换身份 |

纠结 Mayor vs 岛主，本质上是把三件事捆在一起问了：

1. **循环：** Town 是养成模拟，还是竞技主场？
2. **角色：** 玩家是执政官，还是这块地的主人？
3. **地点：** 西部镇、海岛、还是现在这张山谷村？

Mayor 和海岛长官只回答了 2+3，而且用的是同一句台词：「你来管这块地」。  
**真正要先锁的是 1。** 本仓库已定：Town 是展示与轻社交，**不是**与赛季锦标并行的第二养成主循环（见 `docs/CLAUDE.md` §5）。

所以：任何听起来像《Township》《海岛奇兵》的职称，都会 **超卖一个我们不打算做的循环**。

## 2. 先拆开：循环 / 角色 / 地点

### 2.1 循环（已定，主题必须服从）

玩家实际在做的事：

- 去建筑里 **玩游戏**（M1 Gate：Solitaire Parlor → 进局）
- 靠竞技成绩 **解锁永久建筑**（0 个可买）
- 别人能 **看见** 这座主场

玩家 **没有** 在做的事：批地、收税、派工人、升级民居产金币。

因此叙事动词应是 **留下痕迹 / 主场变强**，不是 **执政 / 开发荒地**。

### 2.2 角色（对外一句话，对内一个 id）

好的角色只有一个测试：

> 不解释规则，玩家是否明白「这是我的地，不是服务器公共广场」？

| 职称 | 所有权 | 循环预期 | 换季能力 | 结论 |
|------|--------|----------|----------|------|
| Mayor / 镇长 / 市长 | 偏公共城市 | 市政模拟 | 差（樱花镇长、冬日市长都别扭） | 内部可提，对外不作为品牌 |
| 海岛长官 / Governor | 偏殖民行政 | 同上，更官腔 | 中 | 否决。比 Mayor 更冷 |
| 岛主 / Island Keeper | 这块地是我的 | 轻：拜访、装点、节庆 | 好 | **默认对外职称** |
| King / 领主 | 这块地是我的 | 偏 Clash Royale，已有皇冠纹章 | 中 | 可作高阶称号，不作日常称呼 |
| 无职称，只说 your town | 弱 | 无超卖 | 最好 | 系统文案兜底，但品牌偏淡 |

**岛主不是玩法，是所有权口吻。** 英文用 Island Keeper / host of your isle，不用 Chief（文化负担）、不用 Governor（官腔）。

系统层不要出现 `mayor` 枚举。用 `steward`；UI 再映射成岛主 / 樱花季「馆主」等。

### 2.3 地点（皮，可换）

地点只服务三件事：好不好看、好不好进游戏、好不好换季。

| 地点 | 进游戏隐喻 | 和现有美术 | 和休闲目录 | 博彩观感 | 换季 |
|------|------------|------------|------------|----------|------|
| 西部 Mayfield | 进沙龙 / 客厅 | 与山谷村、樱花季冲突 | 只贴扑克 | 强（Saloon） | 差 |
| 纯热带岛 | 上船 / 进码头 | 要重画 S1 母图 | 三消/方块/Merge 很贴 | 弱 | 好，但「村→城→都市」要圆 |
| 山谷卡通村（现母图） | 进地标 | **已经有** | 中性、像 CR 主场 | 弱 | 中（樱花已能叠） |
| **海滨家园（推荐默认皮）** | 进码头 / 灯塔 / 广场 | 现母图右侧已有河，可长出码头区 | 全目录都能放 | 弱 | 好：夏日码头、夜港、樱花港 |

**海滨家园 = 岛上有一座小镇。** 岛主住在这里；西部沙龙如果还要，降级成「其中一个码头建筑」，而不是世界名。

## 3. 对 Mayor 的具体判断

适合 Mayor 的产品：Town 本身就是玩法（建设、人口、税收）。  
本产品：Town 是 **大厅 + 奖杯柜**。Mayor 会带来三种错位：

1. **公共城 vs 个人主场。** 镇长暗示一座城、许多市民。我们要的是「每人一座、可拜访」。岛主天然是个人的。
2. **西部沙龙 vs 平台定位。** 产品口径是非现金、非博彩向。Poker Saloon 当世界门面，和 Solitaire / Block Blast / Merge 的 CrazyGames 休闲入口打架。
3. **换季。** 已有 `s2-edo-sakura` 和 Town 主题分层（env / accent / facade / full）。Mayor of Mayfield 是锁死的世界，不是可换的皮。

**保留 Mayor 的唯一合法用途：** 对内讨论「玩家对建筑有管辖权」。不要写进 onboarding、document title、商店。

---

## 4. 对「海岛长官 ≡ Mayor」的判断

等价关系成立，而且正是风险：

```
Mayor + 西部镇  ≈  长官 + 海岛
     steward + 地点皮
```

换地点 **能** 解决观感（更休闲、更好换季、更不像赌场）。  
换职称 **不能** 解决循环（长官和 Mayor 一样在卖「你来治理」）。

所以：

- 要海岛：可以，而且作为默认皮优于 Mayfield。
- 要长官：不要。中文用 **岛主**；需要正式一点时用「家园主人」，不用长官 / 总督 / 市长。

## 5. 推荐的玩家向叙事（默认皮）

**身份：** 你是这座海滨家园的岛主。  
**地点：** 一座临水的小家园（不是荒岛求生，不是美国西部）。  
**每天发生什么：** 去码头上的屋子里玩游戏；赢了，广场上会多一样别人看得见的东西。  
**别人来做什么：** 拜访你的岛，看见你的建筑，必要时从公告板发起挑战。  
**不是什么：** 你不是公务员，也不用把岛建成大城市才能玩。

成长阶段（已有 `village → town → city → metropolis → legendary`）对外改口吻，不改数值：

| 内部 stage | 对外（岛主口径） |
|------------|------------------|
| 小村庄 | 荒滩营地 |
| 小镇 | 海滨家园 |
| 城市 | 港湾 |
| 都市 | 夜港 |
| 传奇之城 | 传奇岛 |

内部 id 可继续叫 `town` / `village`。不要为叙事去改表结构。

## 6. M1 建筑怎么讲（先改词，不重画）

M1 工程可以继续跑 Mayfield 原型。**对外文案按岛主映射**；美术未换前允许「西部壳 + 岛主词」短暂并存，但 **document title 不要再写 Mayfield 当品牌**。

| 现在（Mayfield） | 岛主口径 | 功能不变 |
|------------------|----------|----------|
| Town Hall | 岛主小屋 / 灯塔 | 身份、进度、空建筑 |
| Solitaire Parlor | 码头牌屋 | Gate → Solitaire |
| Poker Saloon | 夜航船（M2，可继续 gated） | 扑克；不要当世界门面 |
| Telegraph | 信鸥站 | 拜访 / 消息 |

进游戏的一句口吻：

- 旧：走进沙龙，坐下打牌。
- 新：走上码头，进一间屋子，开一局。

Quest 口吻：

- 旧：`Play 1 game at the Parlor`
- 新：`在码头牌屋打完 1 局`

## 7. 明确不做什么

1. **不为了叙事重做经济或解锁。** 建筑仍然只能竞技解锁。
2. **不把 `/town` 和 CasualTown 做成两个世界。** 玩家只拥有一座主场：`/town` 是壳，CasualTown 的建筑/插画是内容。Mayfield 与山谷村必须收束到同一地点皮。
3. **不把西部镇做成 S0 永久世界。** 它可以当 poker 那一栋的皮肤。
4. **不引入必须天天喂养的吉祥物。** 身份仍由成就与收藏承担；岛主只是称呼。
5. **不在 M1 重画母图。** 先锁口径、改 HUD/Gate 文案与 `townId` 语义；下一张插画再按海滨家园长码头区。

## 9. 若否决本结论，最小替代

只接受一个替代，且必须同时满足「个人主场 + 不卖市政循环」：

- **山谷领主：** 完全跟现有 S1 母图和皇冠纹章走，对外称「领主」而不是岛主。换季弱于海滨，但零地点迁移成本。
- **不要选的替代：** 纯 Mayor of Mayfield、海岛长官、农场主、船长（船长会把所有建筑逼成船舱，比岛更窄）。
