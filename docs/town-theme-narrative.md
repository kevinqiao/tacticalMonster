# Town 主题与叙事决策

> **状态：** 产品口径（叙事 / 角色 / 地点）。不改经济、不改解锁规则。  
> **结论先行：** 玩家向世界是 **岛（Island）**，不是镇（Town）。角色是 **岛主**，不是 Mayor。`town` 只留作内部系统名。

---

## 0. 一句话决策

玩家拥有的是 **一座自己的岛**：玩赢了就留下痕迹，别人能来拜访。  
Town / Mayor / Mayfield 都是工程原型口吻，**不要出现在玩家向文案、标题、商店**。

| 层 | 锁定 | 不锁定 |
|----|------|--------|
| 循环 | 竞技解锁 + 访客可见的主场（已有 Town 原则） | 市政模拟、工人、种田、第二套养成货币 |
| 角色 | 岛主（系统 id：`steward`）永久；赛季不是岛主任期 | Mayor 任期、长官、Chief |
| 玩家向世界 | **Island / 你的岛** | Town / 小镇 / Mayfield 当品牌 |
| 赛季叙事 | **本季岛赛**（岛上举办的竞技季，季末归档旗帜） | 镇长换届、岛主罢免 |
| 产品名 | **Arcade League**（休闲多游戏 + 赛季联赛）；岛不进货架主名 | Isle League、Your Island、Mayfield 当商店主名 |
| 换皮 | 赛季只换岛的外观、岛赛主题与称号文案 | 换循环、换回「一座公共镇」 |

**为什么是岛而不是镇：** 更贴近当前休闲潮流，玩家覆盖更宽（年龄、地区、性别、品类）。见 §2.4。  
**海岛长官更好吗？** 地点对了，职称错了。用 **岛主**，不用长官。  
**岛主任期对不上赛季怎么办？** 不要硬套。岛主是永久主人；赛季是岛上办的 **岛赛**。见 §10。  
**游戏叫什么？** 商店主名锁 **Arcade League**；赛季/世界层用 **岛赛**。不要用 Isle League 当货架名。见 §11。

## 1. 为什么现在会纠结

仓库里其实已经有 **两套 Town、三套皮**，还没有统一「玩家是谁」。

| 表面 | 玩家像谁 | 地点 | 承担的工作 |
|------|----------|------|------------|
| Portal `/town` M1 | 西部小镇的过路人 / 隐含镇长 | Mayfield · Saloon Row（沙尘、扑克沙龙、电报局） | 空间大厅：走进建筑 = 进游戏 |
| CasualTown | 有皇冠纹章的领主 | 山谷卡通村（风车、喷泉、竞技场、招财猫） | 成就展柜 + 轻拜访 |
| 赛季皮肤 | 未定义 | S1 草地天空 / S2 江户樱花 | 换墙纸，不换身份 |

纠结 Mayor vs 岛主，本质上是把三件事捆在一起问了：

1. **循环：** Town 是养成模拟，还是竞技主场？
2. **角色：** 玩家是执政官，还是这块地的主人？
3. **地点：** 西部镇、海岛、还是现在这张山谷村？

Mayor 和海岛长官只回答了 2+3，而且用的是同一句台词：「你来管这块地」。  
**真正要先锁的是 1。** 本仓库已定：Town 是展示与轻社交，**不是**与赛季锦标并行的第二养成主循环（见 `docs/CLAUDE.md` §5）。

所以：任何听起来像《Township》《海岛奇兵》的职称，都会 **超卖一个我们不打算做的循环**。

## 2. 先拆开：循环 / 角色 / 地点

### 2.1 循环（已定，主题必须服从）

玩家实际在做的事：

- 去建筑里 **玩游戏**（M1 Gate：Solitaire Parlor → 进局）
- 靠竞技成绩 **解锁永久建筑**（0 个可买）
- 别人能 **看见** 这座主场

玩家 **没有** 在做的事：批地、收税、派工人、升级民居产金币。

因此叙事动词应是 **留下痕迹 / 主场变强**，不是 **执政 / 开发荒地**。

### 2.2 角色（对外一句话，对内一个 id）

好的角色只有一个测试：

> 不解释规则，玩家是否明白「这是我的地，不是服务器公共广场」？

| 职称 | 所有权 | 循环预期 | 换季能力 | 结论 |
|------|--------|----------|----------|------|
| Mayor / 镇长 / 市长 | 偏公共城市 | 市政模拟 | 差（樱花镇长、冬日市长都别扭） | 内部可提，对外不作为品牌 |
| 海岛长官 / Governor | 偏殖民行政 | 同上，更官腔 | 中 | 否决。比 Mayor 更冷 |
| 岛主 / Island Keeper | 这块地是我的 | 轻：拜访、装点、节庆 | 好 | **默认对外职称** |
| King / 领主 | 这块地是我的 | 偏 Clash Royale，已有皇冠纹章 | 中 | 可作高阶称号，不作日常称呼 |
| 无职称，只说 your island | 弱 | 无超卖 | 最好 | 系统文案兜底；品牌仍应出现「岛」 |

**岛主不是玩法，是所有权口吻。** 英文用 Island Keeper / your island，不用 Chief（文化负担）、不用 Governor（官腔）、不用 Mayor。

系统层不要出现 `mayor` 枚举。用 `steward`；UI 再映射成岛主 / 樱花季「馆主」等。

### 2.3 地点：玩家向锁 Island，内部仍可叫 town

地点只服务三件事：好不好看、好不好进游戏、好不好换季。  
**玩家看见的世界名是岛。** 镇、山谷村、Mayfield 都不是对外世界。

| 地点 | 玩家向？ | 进游戏隐喻 | 覆盖面 | 换季 |
|------|----------|------------|--------|------|
| Town / 小镇 / Mayfield | 否 | 进沙龙、市政厅 | 偏成人、偏欧美市政、偏扑克 | 差 |
| 山谷卡通村（现母图） | 否，过渡美术 | 进地标 | 中性，像 CR 主场 | 中 |
| **Island / 你的岛（锁定）** | **是** | 上船、进码头屋子、上灯塔 | 宽：度假/装饰/轻社交，全年龄 | 好 |

岛上可以有广场、灯塔、码头建筑；那是岛上的地标，**不是把世界改回一座镇**。西部沙龙若还要，降级成「夜航船」这一栋，不当世界名。

下一张主插画按岛来：水域环绕、码头作 Gate、中央仍可以有广场和奖杯。现有山谷母图当占位，不把它写成产品设定。

### 2.4 为什么 Island 比 Town 更贴潮流、覆盖更宽

Town / Mayor 是上一代休闲经营的默认皮（《Township》《CityVille》、西部沙龙）。Island 是这一代主场的默认皮（动物森友会式岛屿、度假岛、合并岛、访问别人的岛）。对本产品更贴的原因：

| 维度 | Town / Mayor | Island / 岛主 |
|------|--------------|---------------|
| 年龄 | 市政、西部沙龙偏少年–成人 | 儿童到成人都能立刻读懂「这是我的岛」 |
| 地区 | 镇长/沙龙偏欧美市政文化 | 岛 = 度假，不需要先懂 Mayor 是什么 |
| 性别与动机 | 建设城市、执政 | 装饰、拜访、收藏、度假——和休闲目录更同向 |
| 品类 | 贴扑克沙龙；三消/方块/Merge 是硬套 | 三消、方块、Merge、接龙都能放进码头屋子；扑克可降级为夜航船 |
| 平台 | 像端游大厅或模拟经营 | 更像 CrazyGames / 短会话：打开就能看见一座亮的岛 |
| 换季运营 | 樱花镇、冬日市都别扭 | 夏日岛、夜岛、樱花港、风暴季都自然 |
| 社交一句话 | 「拜访你的镇」像去别人的城市 | 「拜访你的岛」已经是玩家会的动词 |

覆盖更宽，指的不是「岛比镇多一个玩法」，而是 **第一眼身份更少门槛**：不需要理解镇长、西部、市政厅，也能知道这是我的地、可以去玩、可以给别人看。

不选岛的代价：继续用 Town 当玩家向词，会把产品读成模拟经营或扑克镇，和实际循环（竞技主场）以及实际目录（休闲多游戏）错位。

## 3. 对 Mayor 的具体判断

适合 Mayor 的产品：Town 本身就是玩法（建设、人口、税收）。  
本产品：Town 是 **大厅 + 奖杯柜**。Mayor 会带来三种错位：

1. **公共城 vs 个人主场。** 镇长暗示一座城、许多市民。我们要的是「每人一座、可拜访」。岛主天然是个人的。
2. **西部沙龙 vs 平台定位。** 产品口径是非现金、非博彩向。Poker Saloon 当世界门面，和 Solitaire / Block Blast / Merge 的 CrazyGames 休闲入口打架。
3. **换季。** 已有 `s2-edo-sakura` 和 Town 主题分层（env / accent / facade / full）。Mayor of Mayfield 是锁死的世界，不是可换的皮。

**保留 Mayor 的唯一合法用途：** 对内讨论「玩家对建筑有管辖权」。不要写进 onboarding、document title、商店。

## 4. 对「海岛长官 ≡ Mayor」的判断

等价关系成立，而且正是风险：

```
Mayor + 西部镇  ≈  长官 + 海岛
     steward + 地点皮
```

换地点 **能** 解决观感（更休闲、更好换季、更不像赌场）。  
换职称 **不能** 解决循环（长官和 Mayor 一样在卖「你来治理」）。

所以：

- 要海岛：这是玩家向默认世界，不是「也可以」的备选皮。
- 要长官：不要。中文用 **岛主**；英文用 your island / Island Keeper。不用长官 / 总督 / 市长 / Mayor。

## 5. 推荐的玩家向叙事（默认世界 = 岛）

**身份：** 你是岛主。  
**地点：** 你的岛（不是荒岛求生，不是美国西部小镇，也不是一座要你执政的城市）。  
**每天发生什么：** 去码头上的屋子里玩游戏；赢了，岛上会多一样别人看得见的东西。  
**别人来做什么：** 拜访你的岛，看见你的建筑，必要时从公告板发起挑战。  
**不是什么：** 你不是镇长，也不用把岛建成都市才能玩。

成长阶段（已有 `village → town → city → metropolis → legendary`）对外改口吻，不改数值：

| 内部 stage | 对外（岛口径） |
|------------|----------------|
| 小村庄 | 荒滩营地 |
| 小镇 | 你的岛 |
| 城市 | 港湾岛 |
| 都市 | 夜岛 |
| 传奇之城 | 传奇岛 |

内部 id / 路由可继续叫 `town`、`/town`、CasualTown。**不要为叙事去改表结构和 URL。** 玩家向字符串一律用 island / 岛，不用 town / 小镇。

## 7. 明确不做什么

1. **不为了叙事重做经济或解锁。** 建筑仍然只能竞技解锁。
2. **不把 `/town` 和 CasualTown 做成两个世界。** 玩家只拥有一座岛：`/town` 是壳，CasualTown 的建筑/插画是内容。Mayfield 与山谷村都必须收束到同一座岛。
3. **不把西部镇做成 S0 永久世界。** 它可以当 poker 那一栋的皮肤。
4. **不引入必须天天喂养的吉祥物。** 身份仍由成就与收藏承担；岛主只是称呼。
5. **不在 M1 重画母图。** 先锁口径、改 HUD/Gate 文案；下一张插画按 **岛** 来画（水域环绕 + 码头 Gate），不要再画一座内陆镇。
6. **玩家向禁止再用 town 当世界名。** 代码、路径、表名可以继续 `town`；UI、标题、任务、商店写 island / 你的岛。
7. **不把赛季写成岛主任期或换届。** 岛主永久；赛季用岛赛。不要为了保住 Mayor 的任期隐喻而改回镇。
8. **不以岛/镇/Mayor 做商店主名。** 货架主名锁 **Arcade League**；**岛赛**只用于赛季与进游戏后的世界，不用 Isle League 当 App 名。

## 9. 若否决本结论，最小替代

玩家向世界已锁 Island。若只否决「岛主」这个词，仍须保持岛，可降级成无职称的 **your island**。

- **可接受的弱化：** 不称呼岛主，只说「你的岛」。
- **不要选的替代：** Town / Mayor of Mayfield、海岛长官、山谷领主当世界身份、农场主、船长（船长会把所有建筑逼成船舱，比岛更窄）。

现有 S1 山谷母图可以继续当占位图，直到下一张岛插画；**占位图不等于产品设定仍是镇。**

## 10. 赛季怎么映射：不要做「岛主任期」

Mayor 的任期能对上 season，是因为它把 **身份** 和 **赛季时钟** 焊在一起：这季你是镇长，季末换届。  
岛主焊不住同一根线：岛主是主人，不是选上来的官。硬说「本届岛主任期」会假。

而且这根线和 **已有系统是拧的**：Town / 建筑跨季永久、不随赛季重置；赛季分、Pass、周联赛才重置。若 Mayor 换届，为什么镇还是你的？只能再补「连任」。岛主 + 岛赛不用补。

正确拆法：

| | 永久（不随赛季清） | 本季（随赛季转） |
|--|-------------------|------------------|
| 玩家是谁 | 岛主，这座岛是你的 | 本季岛赛的参赛者 |
| 对应系统 | 建筑解锁、Town Level、赛季档案室 | 赛季分、段位 UI、Pass、周联赛 |
| 季末发生什么 | 岛还在；本季旗帜/通行证进档案室（已有 `season_archive`） | 段位与 Pass 按赛季规则收束，下一季岛赛开幕 |
| 玩家向口吻 | 你的岛 | S2 樱花岛赛进行中 |

映射表（对内 id 不动，只改口吻）：

| 系统 | Mayor 任期口吻（弃用） | 岛赛口吻（采用） |
|------|------------------------|------------------|
| Season | 第 N 届任期 | 第 N 届岛赛（S2 樱花岛赛） |
| 周联赛 | 本周市政考核 | 本周赛程 / 本周岛赛积分 |
| Battle Pass | 竞选纲领 | 本季岛赛通行证 |
| 段位 | 治绩 | 本季成绩 |
| 赛季皮肤 | 新市政装修 | 本届岛赛主题（夜岛、樱花港） |
| 冠军柱 / 档案室 | 历届政绩 | 历届岛赛旗帜（建筑已按这个写） |

所以：岛主不别扭，别扭的是把 **官职任期** 套到 **主人** 头上。岛只提供主场；**竞技主线仍由岛赛承担。**

不要发明第二套「岛主选举」循环。

## 11. Arcade League vs Isle League：锁 Arcade League

两个名字都带 League，竞技半边一样。差别在前半截承诺什么。

| | **Arcade League** | **Isle League** |
|--|-------------------|-----------------|
| 货架第一眼 | 休闲小游戏合集 + 联赛 | 一座岛 + 联赛 |
| 和真实循环 | 一致：接龙 / 方块 / Merge + 赛季分 | 半一致：岛是主场，不是玩法 |
| 会招来谁 | 来玩游戏、比分的人 | 一部分来装扮/经营岛的人 |
| 做错的代价 | 偏泛，CrazyGames 上 arcade 很多 | 招来本产品 **明确不做** 的养成用户 |
| 中文 | 不要译成「街机联赛」；可保留英文，或 UI 里说联赛 | **岛赛** 很漂亮，但那是赛季名，不是货架名 |
| M1 | 现在就能用，不依赖岛的美术 | 山谷村 / Mayfield 占位时，名字在说谎 |
| 和三层结构 | 主名=竞技品类，岛留在进游戏后 | 把世界塞进主名，和「岛不当商店主名」打架 |

**锁：货架 / `<title>` / CrazyGames 用 Arcade League。**

原因就一条：本产品的差异化是 **多休闲玩法 + 统一赛季联赛**，不是岛。岛是进门之后的主场和潮流皮。Arcade 说清品类；League 说清玩法（已有 weekly league）。Isle 说清的是皮，会把皮卖成玩法。

Isle League / 岛赛 不是废词，降到它该在的层：

| 层 | 名字 |
|----|------|
| 产品主名（商店、标题） | **Arcade League** |
| 世界（地图、拜访） | 你的岛 |
| 本季（Pass、段位、主题） | **岛赛**（S2 樱花岛赛） |

副标题（商店描述第一句）：`Play casual games. Climb the season. On your island.`
