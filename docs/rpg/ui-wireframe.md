# Portal RPG UI 线框

状态：accepted　日期：2026-08-18  
架构：[architecture.md](./architecture.md)  
类型 SSOT：`src/convex/rpg/architecture.ts`  
规格源：`src/convex/rpg/uiWireframe.ts`

Canvas 只作预览，不进仓库。实现按下列 path / layout / ascii。

## 壳

对标 `/town`，五栏顺序固定，battle 居中：

1. `shop`　`/rpg/shop`　商店
2. `rewards`　`/rpg/rewards`　奖励
3. `battle`　`/rpg`　对战
4. `league`　`/rpg/league`　联赛
5. `me`　`/rpg/me`　图鉴

底栏：商店　奖励　对战　联赛　图鉴  
对局全屏隐藏底栏。HUD 无图鉴战力。图鉴 HUD 多当前库尘。

## 导航

对战：馆 → 桌(gameType) → 小时题。  
图鉴：库(gameType) → 筛选 → 卡。  
同一批游戏，父级不同。新游戏加桌 + 加 chip，不加底栏。

| 层 | 在哪 | 切什么 | 不要做成 |
|---|---|---|---|
| L0 | 底栏五键 | 商店 / 奖励 / 对战 / 联赛 / 图鉴 | 第 6 个游戏 Tab |
| L1 | 图鉴 HUD 下横滑 chip | TCG / 战棋 / 新游戏 | 两座玩法馆大门 |
| L2 | 当前库内部 | 已有、费用、稀有… schema 随库变 | 一套筛子硬套所有游戏 |
| L3 | 网格 → 详情 | 当前 Arena 的卡或英雄卡 | 混库一张大网 |

## 屏清单

### 商店　`/rpg/shop`

CTA：购买

- rpg:{rpgId} 钱包花 coin 买票。
- v1 不开包。chess/tcg 卡不进 Portal 商店。
- 跟 Town shop 同构。

```
┌ 金 III          周 4 胜          1200 · 票 3 ┐
│ 商店                                         │
│ rpg 钱包 · 花 coin 买票                      │
│ ┌─────────────────────────────────────────┐ │
│ │ 门票 x1                          100    │ │
│ └─────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────┐ │
│ │ 门票 x5                          450    │ │
│ └─────────────────────────────────────────┘ │
│ v1 不开包，不卖 chess / tcg 卡               │
├ [商店]  奖励   对战   联赛   图鉴           ┤
```

### 奖励　`/rpg/rewards`

CTA：领取

- 20 节点镜像 Town：多数 coin，8/16 ticket，4/20 称号。
- XP：秀斗 +10，试炼成功 +4。领取不是拆包。
- Pass 不是独立 Tab，并进本栏。

```

│ 任期奖励 · 节点 8                            │
│ ████████░░░░░░░░  下一档 ticket x1           │
│ 已领：coin 460 · 票 1 · 称号 1               │
│ ┌─────────────────────────────────────────┐ │
│ │                 领取                    │ │
│ └─────────────────────────────────────────┘ │
├ 商店  [奖励]  对战   联赛   图鉴             ┤
```

### 对战首页　`/rpg`

CTA：进秀斗 / 进试炼

- 先选竞技形态。不要放 chess/tcg 两个大门。
- 秀斗计入周榜，试炼不计周分。
- 副行倒计时把人推进馆，不是开包。

```

│ 对战 · 本小时题 37 分后刷新                  │
│ ┌─────────────────────────────────────────┐ │
│ │ 秀斗馆                                  │ │
│ │ 多人同题 · 计入周榜                     │ │
│ └─────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────┐ │
│ │ 试炼馆                                  │ │
│ │ 单人挑战 · 不计周分                     │ │
│ └─────────────────────────────────────────┘ │
├ 商店  奖励  [对战]  联赛   图鉴             ┤
```

### 馆内桌　`/rpg/hall/:kind`

- 每桌：gameType、本小时 Boss 缩略、倒计时。
- 点桌进预览，不直接开战。
- 秀斗标明计入周榜；试炼标明产 Pass XP。

```
┌ 金 III          周 4 胜          1200 · 票 3 ┐
│ 秀斗馆 · chess / tcg 桌共用周分              │
│ ┌─────────────────────────────────────────┐ │

│ └─────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────┐ │
│ │ tcg 桌 · 同一小时 · 另一份牌规          │ │
│ └─────────────────────────────────────────┘ │
├ 商店  奖励  [对战]  联赛   图鉴             ┤
```

### 小时题　`/rpg/table/:id`

CTA：组 4 人 / 组套

- 看题是公平叙事入口。主按钮不是匹配。
- Boss 固定。克制只加分，不挡进场。
- chess 组 4 人；tcg 组套。

```

│ ┌─────────────────────────────────────────┐ │
│ │           地图预览 · 固定 Boss          │ │
│ └─────────────────────────────────────────┘ │
│ 典狱官 · 高防 / 召唤                         │
│ 基础 4 人可通关。克制只加分。                │
│ ┌─────────────────────────────────────────┐ │
│ │                 组 4 人                 │ │
│ └─────────────────────────────────────────┘ │
├ 商店  奖励  [对战]  联赛   图鉴             ┤

### 对局　`fullscreen`

CTA：交卷

- 全屏，隐藏五栏。不露 coin、不露图鉴。
- chess 棋盘；tcg 手牌加 Boss 血条。
- Boss 数值固定，不跟个人队伍缩放。

```
┌ 典狱官 24/30     回合 4              交卷 ┐
│                                           │
│              chessArena 棋盘              │
│                                           │
├ 守卫   刺客   治疗   坦克                 ┤
```

### 结算　`modal`

CTA：再战本题

- 秀斗才有周分，本小时只记最高一局。
- 尘标明来自哪座 Arena。
- 再战锁进场 seed；过点提示已换题。

```
┌ 金 III          周 4 胜          1200 · 票 3 ┐
│ 1840 分 · 同桌第 2                           │
│ 秀斗周分 +3 · 本小时最高已记                 │
│ +40 coin · Pass +10 XP · 尘 +8（chessArena） │
│ ┌─────────────────────────────────────────┐ │
│ │                再战本题                 │ │
│ └─────────────────────────────────────────┘ │
│ 或回馆换 tcg 桌                              │
├ 商店  奖励  [对战]  联赛   图鉴             ┤
```

### 联赛　`/rpg/league`

CTA：回对战看题

- 一条 rpg: 周榜。不按图鉴战力排序。
- Pod 约 30 人。升段 1-3，保段 4-8。
- 再战秀斗仍回馆看题。

```
┌ 金 III          周 4 胜          1200 · 票 3 ┐
│ 金 III · Pod 12/30                           │
│ chess + tcg 秀斗合计                         │
│ 1 你                              28 分      │
│ 2 对手 A                          25 分      │
│ 3 对手 B                          21 分      │
│ 升段区 1-3 · 保段 4-8                        │
├ 商店  奖励   对战  [联赛]  图鉴             ┤
```

### 图鉴 · 卡册　`/rpg/me/:gameType`

CTA：打开卡

- 默认 `/rpg/me/tcg`。一枚 chip 一个 gameType。
- 网格只渲染当前 Arena。新游戏加 chip，不加底栏。
- 不在这里组队。不要叫战队。

```

│ [TCG]  战棋  （新游戏横滑）                  │
│ tcgArena · 48/72                             │

│ │铁墙│ │治疗│ │火球│                         │

│ └────┘ └────┘ └────┘                         │

│ │ 新 │ │400 │ │100 │                         │
│ └────┘ └────┘ └────┘                         │

### 图鉴 · 卡详情　`/rpg/me/:gameType/:cardId`

CTA：合成 / 返回卡册

- 数值只读所属 Arena。未满且尘够才显示合成。
- rank_road 不可分解。不从详情进对局。
- 新角标点进后消失。

```
┌ 金 III     1200 · 票 3              尘 340 ┐
│ 火球 · 4 费法术 · 稀有                       │
│ ┌─────────────────────────────────────────┐ │
│ │ tcgArena · 造成 6 点伤害                │ │
│ └─────────────────────────────────────────┘ │
│ 张数 1/2 · 合成 100 尘                       │
│ [合成第 2 张]     [返回卡册]                 │
├ 商店  奖励   对战   联赛  [图鉴]            ┤
```

### 图鉴 · 合成确认　`modal · craft`

CTA：确认

- 扣当前 Arena 尘。结果确定，不是开包。
- tcg 尘不能合成 chess 卡，反过来也不行。

```
┌ 金 III     1200 · 票 3              尘 340 ┐
│ 合成 火球                                    │
│ 100 tcgArena 尘 · 余额 340 → 240             │
│ 火球 1/2 → 2/2。不是开包。                   │
│ [确认]                 [取消]                │
├ 商店  奖励   对战   联赛  [图鉴]            ┤
```
