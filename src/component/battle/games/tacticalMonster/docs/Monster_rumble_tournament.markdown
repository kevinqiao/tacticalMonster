# Monster Rumble Tournament  
怪物战棋锦标赛 · 2025 完整设计文档（中文版）

## 一、游戏概览
- **类型**：移动端F2P回合制策略战棋 + PVE多人实时锦标赛
- **核心循环**：10-20人同步打相同AI Boss → 实时分数排行 → Top3分金币池（4-5分钟一局）
- **美术风格**：Q版神话怪物 + 科幻裂隙主题（fbx,glb格式3d + 粒子特效）
- **商业目标**：D1留存80%、D7 50%、D30 ARPU $5+

## 三、核心玩法：PVE锦标赛（单局4-5分钟）

### 流程
1. 选Tier → Power±10%匹配10-20人（<30s）
2. 选4怪部署Hex位置
3. 回合制战斗（移动/技能/大招4能量）
4. 实时分数排行（左侧Top10）
5. 结束Top3分金币池 + 宝箱20%概率

### 分数公式（技巧占70%）
总分 = 击杀×10 + 速通×20% + 无损×2 + Combo分
Combo分 = 链长×100 × 1.5 × (Lv/23×0.5) × 克制1.2

## 五、怪物系统（90+种）

- **稀有度**：绿（Common）≈50种、蓝≈25、紫≈10、橙≈5（固定，无同名多稀有）
- **成长路径**：
  - 碎片合成星1-5（每星+200HP等）
  - 金币喂Lv1-23（HP+4%/Lv，Damage+3.5%）
- **技能进化节点**：
  - Lv5：主动技能1
  - Lv11：被动技能 + 魔防解锁
  - Lv15：大招Lv2
  - Lv20-23：全技能+30% + 被动2/3

**S级绿卡举例**（前期神卡）：
- Medusa：Lv11被动敌闪避-25%
- Bigfoot：Lv11 DoT Not（免疫持续伤害）
- Harrison：Lv11先攻拉敌
